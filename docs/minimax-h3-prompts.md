# MiniMax H3 プロンプト設計ガイド（15秒CM型）

公開されている高品質なプロンプト2本（フラットイラスト講座CM／キネティックタイポグラフィCM）
から抽出した共通構造。この「文法」を守れば、題材を差し替えるだけで仕事向けの動画
（サービス紹介・社内告知・イベント告知など）にも応用できる。

プロンプト自体は GPT 等に書かせてよい。重要なのは**以下の骨格を必ず含めさせる**こと。

## 共通する10の設計原則

1. **参照画像アンカー** — `対象動画の0.000秒地点で <Image1> を完全に参照する` と宣言し、
   キャラクター・色・構図を画像由来で固定。終盤で「元の世界に戻る」ショットを
   入れると中盤が暴れても一貫性が保たれる。
2. **絶対タイムコードのショット割り** — 全長を 15.000 秒に固定し、各ショットの開始時刻を
   `0:02.400` のように絶対時刻で指定。「次に」「その後」などの相対指定は使わない。
   ショット数は 6〜10 が目安。
3. **表示テキストの完全固定** — 画面に出す日本語を一字一句書き切り、
   「誤字・文字化け・欠落・勝手な文字の発明・英語への置換を禁止」と明記。
   日本語グリフ崩れ対策として最重要。
4. **テキスト＝主役宣言** — 「文字は字幕ではなく主役のオブジェクト」と宣言し、
   バウンド出現／巨大化／分解→再構成／ドミノ倒し等の**モーション文法を動詞で列挙**する。
5. **カラーパレット厳守＋禁止色** — 使う色を名前で列挙し、
   蛍光色・ネオングラデーション・金属色など**使わない色も明記**する。
6. **カメラ完全固定** — ズーム・パン・チルト・手ぶれを禁止し、
   動きはタイポグラフィ・図形・キャラクターのアニメーションだけで作らせる。
7. **可読ホールド** — 重要な文の完成後に `約0.35〜0.45秒のホールド` を数値で指定する。
8. **音の3層分離** — ①効果音（動きに同期、セリフなし）②BGM（楽器編成と展開）
   ③アクセント同期表（`00:03.150 — 「知識」のドミノ` のようなビートマップ）を
   別セクションで書く。**映像側の文言と音側の文言を一致させる**こと
   （例：片方だけ「月額99万円」になっている等の不一致はテキスト揺れの原因になる）。
9. **終端の完全静止** — 最後の 0.5 秒前後は「全要素を完全静止、点滅・揺れ禁止」と
   指定し、`15.000秒で音楽を明確に完結` させる。エンドカードが綺麗に止まる。
10. **絶対禁止事項リスト** — キャラ改変・余分な指・写実化・3D化・複雑背景・
    レンズフレア・ナレーション等、起きてほしくない事故を最後にまとめて列挙する。

## 追加テクニック（縦型サービスCM例より）

スマホアプリ紹介CM（縦9:16・冷蔵庫撮影→献立提案サービス）の例から学べる追加パターン:

- **アスペクト比の明記** — `vertical 9:16` のように冒頭で宣言（スマホ向け広告に必須）
- **参照画像の「写り込み」禁止** — 参照画像をサムネイル・スクリーンショット・
  ブラウザ画面として動画内に表示するなと明記。参照画像がそのまま画面内に
  貼り付けられる事故を防ぐ
- **プロダクト・オブジェクト宣言** — 「スマホがこのCMの主役オブジェクト」と明記し、
  モーションの中心に据える
- **UI の解像度ガード** — 「読めない極小のアプリUIテキストを描くな」
  「アプリ画面は大きな食材カードとアイコンだけ」と指定。生成AIが描きがちな
  ぐちゃぐちゃの偽UIを防ぐ
- **テキスト固定の適用範囲を UI にも拡大** — スローガンだけでなく
  「通知・価格・評価・インターフェース文言の発明も禁止」
- **1画面1フレーズ** — ベネフィット3連打では「常に1フレーズだけ表示」と明記
- **「本物の結果シーンであること」指定** — 最終カットは
  「アイコングリッドやソフトのサムネイルではなく、実際のサービス利用結果に見えること」

## 実写・プレミアム型（化粧品CM例より）

実写調の10秒縦型シャンプーCM例より。フラットイラストでなくても同じ10原則が
そのまま通用することが分かる。追加で学べるテクニック:

- **尺は可変** — 15秒固定ではなく10.000秒でも同じ文法で書ける（絶対タイムコードは
  サブ秒精度 `00:00.450` まで刻める）
- **コンセプトアーク宣言** — 「乱れた動きが滑らかな秩序に変わる。冒頭は流動的で
  未解決、終端は整列して静か」と**商品ベネフィットを映像の変化そのもの**に翻訳して
  1文で宣言する。ヘアケアの「まとまり」を motion design の「整列」で表す発想
- **モーション語彙の制限** — 「使ってよい動きは4種のみ（液体波・タイポワイプ・
  制御された反復・グリッド整列）」と列挙し、それ以外を禁止。効果の氾濫を防ぐ
- **統合宣言** — 「商品・モデル・液体・文字・色面は別レイヤーの重ね貼りではなく
  一つの構成として相互作用すること」。文字が髪の後ろを通り、液体で屈折する等の
  レイヤー関係を明示する
- **色の役割固定** — パレット列挙に加えて「各色の役割を一貫させる」と宣言
- **架空人物の明示** — 「実在の人物に似せない架空の日本人女性」「解剖学的に正しい
  手と身体」— 肖像権対策と生成事故対策を兼ねる
- **ネガティブの精度** — 「ダーク・クリニカル・ベージュ・コーポレート・
  ありがちな高級感になるな」「Canvaテンプレ・LP風構成・ストックフォト的表情・
  インフルエンサーポーズ禁止」など、**避けたい「あるある」を固有名詞レベルで潰す**

注意: この例には音のセクション（soundscape / music）がない。無音でよい場合を除き、
流用時は他の例と同様に音の3層を書き足すこと。なお表示テキストの一貫性チェックは
この例は合格（断片「新発想」「まとまり」等がすべて正式コピーの部分集合になっている）。

## 見つかった不一致バグの例（流用時は要修正）

- 講座CM例: 映像側「月額50万円」に対し音楽側だけ「月額99万円」
- 縦型サービスCM例: Beat 2 では「MOGUQ」、エンドカードでは「MOGU-Q」と表記が揺れている

→ **表記揺れはそのまま文字化け・テキスト崩れの原因になる**ため、
プロンプト完成後に「画面に出る全文字列を抜き出して一覧化し、一致を確認する」
チェックを必ず行うこと（GPTに書かせた場合も同様）。

## 15秒CMの定番構成（起承転結）

| 区間 | 役割 | 例 |
|---|---|---|
| 0–2.5秒 | つかみ・問題提起 | 「〜、難しいと思っていませんか？」＋巨大な「？」 |
| 2.5–5秒 | 課題の列挙 | 「知識」「費用」「時間」をドミノ倒し |
| 5–10秒 | 解決・製品名・特徴3点 | 「でも実は…」→ 製品名ドン → 特徴カード×3 |
| 10–13秒 | 仕組み・ベネフィット | 「A＋B→C」の変形、キーフレーズ強調 |
| 13–15秒 | エンドカード・CTA | 講座名/製品名＋一言、完全静止で締め |

## 仕事に使うときの差し替えポイント

- **参照画像**: 自社キャラ・ロゴ入りキービジュアル1枚（フラットイラストが安定）
- **表示テキスト**: 課題3語／特徴3点／CTA の計7〜8フレーズを差し替えるだけでよい
- **誇張表現に注意**: 数値目標は「目標：〜」のように aspirational と明記する書き方が誠実
- 実行は `minimax_h3.bat` で起動 → Template Library > Video > MiniMax H3 の
  R2V（参照画像あり）ワークフローにプロンプトと画像を投入
